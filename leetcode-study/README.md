# LeetCode Visual Study

Open `index.html`. Each problem: **Question → Code → Flow → Diagram** with Prev / Play / Next (also ← → and space).

```
leetcode-study/
├── index.html            problem picker
├── assets/               shared style.css + player.js
└── 1071-gcd-of-strings/  one folder per problem
    ├── index.html
    └── problem.js        question, code, steps (edit this to change a lesson)
```

To add a problem: copy a folder, edit `problem.js`, add a card to `index.html`.
